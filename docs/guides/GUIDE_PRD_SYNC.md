# Master PRD 확인·동기화

계획·구현·리뷰 전 또는 프로젝트 변경 기록 시 관련 절을 읽는다. 제품 요구사항을 복제하는 문서가 아니라 원본 관리 절차다.

- 실제 원본 링크·문서 ID는 Git에서 제외하는 `docs/private/PRD_SOURCES.md` 또는 사용자가 현재 세션에 제공한 값으로 확인한다. 공개 문서·PR·커밋 메시지에는 내부 링크·ID를 복사하지 않는다. 새 환경에서 이 로컬 파일이 없으면 연결된 원본을 확인하거나 사용자에게 식별 정보를 요청하고, 제품 판단은 확인 후 진행한다.
- 제품 요구사항은 Master PRD를 최우선으로 한다. 별도 로컬 PRD나 개발용 복제본은 유지하지 않으며, 로컬 문서·과거 대화·AI 메모와 충돌하면 원본을 따른다. `AGENTS.md`는 작업 절차를 정한다. 행사 규정·API 사실은 공식 출처로 검증하고 원본의 미검증 표시를 유지한다.
- 계획·구현·리뷰 전에 원본의 최신 관련 절을 직접 읽는다. 같은 세션에서 원본이 변경되지 않았을 때만 읽은 내용을 재사용한다. 로컬 스킬과 훅도 `AGENTS.md`에 연결된 원본을 기준으로 한다.
- 모든 프로젝트 변경은 원본에 기록한다. 요구사항·범위·UX·우선순위·아키텍처·완료조건 변경은 관련 본문과 변경 이력을 함께 수정하고, 구현·버그 수정·설정·문서 변경은 날짜와 결과를 변경 이력에 간단히 남긴다. 상세 구현 기록은 저장소 링크나 요약으로 연결하며 자격증명·개인 서사 원문은 기록하지 않는다.
- 결정은 `CONFIRMED`, `PROPOSED`, `OPEN`으로 구분한다. 사용자와 합의되지 않은 제안을 확정 요구사항으로 바꾸지 않는다. 원본을 갱신한 뒤 영향받은 README·작업 문서를 동기화한다.
- 원본 수정 직전에 최신 revision을 확인하고 동시 편집을 보존한다. 수정 후 다시 읽어 반영을 검증한다. 완료 보고에 원본·로컬 반영 여부와 미완료 동기화를 명시한다.
- Drive 읽기·쓰기 권한이나 연결이 없으면 제한과 동기화 대기 내용을 알린다. 로컬 문서를 임의로 원본으로 삼거나 전체 완료로 보고하지 않는다. 원본 미확인 내용에 의존하는 결정은 보류하고 독립적인 작업만 진행한다.
