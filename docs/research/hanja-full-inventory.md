# 인명용 한자 전체 수집 후속 점검

2026-11-04, `feature/hanja-pdf`. 사용자 요청에 따라 이름 생성기·PR보다 전체 자료 확보를 먼저 진행했다. 결과와 재현 명령은 [전수 자료 안내](../../data/hanja/README.md)에 있다. 전체 9,495코드를 Git 제외 캐시만이 아니라 저장소에 포함할 분할 자료로 정리했다. 이 파일은 조사 기록이며 제품 요구사항의 원본을 대신하지 않는다.

법원 전체 색인 원문에 libhangul의 한국어 자료와 Unicode 18 Unihan을 대조했다. 뜻 추출이 비어 있던 표준 문자 94자를 Wiktionary 공개 API 5회로 추가 조사하여 19자의 명시적인 영어 뜻을 확보했다. 번역·독음별 뜻 검수 완료로 바꾸지 않았다. 의미가 없는 `rfdef`, 단어에서만 사용된다는 템플릿, 이체자 링크만 있는 항목은 뜻으로 세지 않는다. 남은 표준 문자 75자, 전용 코드 405개, 독음별 뜻 누락·풀이 잔여 문자열은 현재 [검색 데이터 안내](../../data/hanja/README.md)의 미해결 색인에 보존했다. 제외된 항목도 전체 원문 목록에 남는다.

추가로 [EDRDG KANJIDIC2](https://www.edrdg.org/kanjidic/kanjd2index_legacy.html)의 2026-11-04, database `2026-308`, file version 4를 내려받아 남은 75자를 대조했다. 원본 gzip SHA-256은 `e26e34c9187a786bf1f0b21f87e311a9b0ed644aefe9693d10bdc7cb8643d8e0`이다. 侾·俽·僌·姟·桗·欗·炛·琑·靕·晭 10자가 있으나 전부 영어 meaning이 비어 있어 추가 뜻 근거는 0개였다. 다른 글자의 뜻을 빌리지 않았고 KANJIDIC2 데이터·SKIP 코드·독음은 저장소에 도입하지 않았다. [공식 이용 조건](https://www.edrdg.org/edrdg/licence.html)은 CC BY-SA 4.0 외 갱신·일부 필드의 별도 조건을 설명한다.

전용 코드 조사에서는 법원 공개 JavaScript, `a0111` 상세 응답, 공식 인명용 CSS를 확인했다. 상세 응답에는 가라는 독음과 A형 코드가 있고 표준 Unicode 대응이나 뜻이 없다. 별도 폰트 요청은 빈 파일을 반환해 문자 대응 근거로 사용하지 못했다. [Unicode의 한국 독음·인명 한자 제안 문서](https://www.unicode.org/L2/L2020/20082-update-korean.pdf)는 2018년 목록을 기반으로 하며 이체자·독음의 대응이 단순하지 않음을 보여준다. 최신 법원 코드와의 매핑표로 사용하지 않는다. [KRName IVD 등록](https://www.unicode.org/ivd/krname/)도 조사했으나 IVD 원문 두 버전의 다운로드가 HTTP 522로 실패했다. 전용 코드 405개를 표준 문자로 바꿨다고 주장하지 않는다. 폰트·이미지를 재배포하지 않았다.

전체 목록 보존과 뜻·독음·이체자 검수의 완료는 구분한다. 현재 9,015 표준 문자에 뜻 근거가 있지만 전체 뜻 검수, 1,109 허용 코드/독음 쌍의 한국어 뜻 연결, 전용 코드 405개의 정확한 문자 대응, 법적 별표와 전체 기술 코드의 대응은 남아 있다. 344자 선별 편집 자료를 생성 후보의 상한으로 삼지 않으며, 미해결 자료를 완료 처리하여 생성기로 넘기지 않는다.

Meta 호출 0회. 새 패키지 설치 없음. 전체 수집·검수 마무리는 아직 미완료이며 커밋·PR·생성기 구현은 하지 않았다.

## 사용자 요청 정리 후 상태

2026-11-04 후속 요청으로 채택하지 않은 OCR 실험과 중복 산출물을 정리했다. `.tools/hanja-pdf`, PDF 변환기·전용 테스트·도구 메타데이터/잠금 파일, 전체·미리보기 OCR 출력, 이전 한자 대조/검수 출력과 중복 법원 캐시를 삭제했다. 공식 응답은 `data/hanja/sources.json`와 삭제한 캐시의 40개 근거 파일이 모두 동일함을 확인한 뒤 한 벌만 남겼다. 고정 rutopio 원본은 `data/sources/hanja-rutopio.json`, 기존 검수용 Unihan 17 ZIP은 `data/sources/Unihan17.zip`으로 이동해 보존했다. 과거 대조 목록이 보존 입력에서 바이트 단위로 재현되는지 확인했고 새 원문 경로로 344자 검수도 통과했다.

삭제한 중간 결과는 재생성 가능하며 [갱신된 도구 명령](../../tools/hanja-catalog/README.md)을 따른다. 사용자 PDF·전체 한자 원문/분할 자료·편집 검수 JSON/표·미해결 목록·출처/라이선스·서비스 사주 색인은 보존했다. 이 절 이전의 경로와 검증 수치는 해당 실행 당시의 기록이다. 정리 후 제거한 OCR 전용 4개 테스트를 제외한 Python 72개가 통과했고, 전체 한자 검사와 344자 실제 근거 검증도 통과했다. 삭제한 파일은 1,594개, 합계 371,807,793바이트다. 한자 데이터의 미해결 상태와 생성기 미구현은 바뀌지 않는다.


## 검색·파일 구조 통합

후속 compact 요청으로 파일 크기에 맞춘 200개 단위 분할과 별도 보고서를 제거했다. `data/hanja/` 128파일·20,986,964바이트를 원문/검색/안내 3파일로 바꿨다. 원문 `sources.json`은 4,405,416바이트, 검색 `catalog.json`은 4,026,163바이트다. 원문과 검색 자료 합계 약 8.4MB로 기존 대비 약 60% 감소했다. 안내 문서 크기는 별도다. 과거 source 파일명은 통합 원문 안의 근거 ID로 남으며 실제 파일은 아니다.

71개 원문 문서의 바이트와 해시를 모두 복원할 수 있고, 전수 9,495개 항목을 통합 전 데이터와 전체 비교해 일치했다. 같은 뜻·독음의 텍스트를 하나로 합치면서 출처 참조는 유지한다. 별도 소스 분할 스크립트는 제거했다. 기존 수집기·344자 검수기는 통합 원문을 직접 읽도록 연결했으며 과거 대조 review.json 해시와 실제 검수 결과가 그대로다.

글자·허용 독음·뜻 키워드·선택 검수 소재·미해결 사유의 역색인을 검색 파일에 포함했다. Catalog 인스턴스는 파일을 한 번만 읽고 일반 검색은 원문에 접근하지 않는다. 작은 단어 색인에서 부분 문자열을 찾은 뒤 코드 집합을 교차하고 같은 뜻/독음인지 확인한다. 테스트 중 보조 사전에 김=쇠가 포함된 실제 사례를 발견해 법원 주 풀이 > 법원 일반 사전 > 보조 사전 순의 독음별 검색 정책을 적용했다. 하위 자료의 추가/상충 뜻은 reference_only로 보존한다. 금속 소재를 김 독음에 옮기거나 영어 글자 뜻을 김 독음의 뜻으로 반환하지 않는다.

이 환경의 단회 측정에서 첫 로드 약 85ms, 100회 반복 조회의 중앙값은 글자 0.003ms/독음 0.023ms/독음+뜻 0.283ms/소재+독음 0.004ms였다. 캐시된 로컬 프로세스 측정이며 서비스 지연이나 다른 환경의 성능 보장은 아니다. 테스트는 선형 조회와 색인 결과의 동등성, 원문 미접근·단회 로드, 독음/뜻/소재 경계, 중복 근거 유지, 원문 변조·경로 거부와 재생성 일치를 포함한다. 두 JSON만 공개 검사 8MB 한도를 적용하며 다른 파일의 1MB 제한과 모든 비밀 검사는 유지한다.

완료 검증(2026-11-05): Python 81개 통과, 실제 compact `--check` 통과, 김+쇠 검색 결과 없음, 기존 344자 근거 검증과 과거 대조 해시 유지 확인. 변경된 25개 파일만 복사한 격리 Git 스냅샷의 공개 검사도 통과했다. 코드 4개(loader/검색·수집기·검수기·공개 검사) Codex Security 정적 검사 완료, 발견/deferred/open 0개이며 최종 코드가 검사 사본과 동일하다. 앱·배포·실행 중 경쟁 조건까지 감사한 것은 아니다. ## 전수 뜻·독음 근거 대조 (2026-11-05)

사용자 요청으로 전체 9,495코드, 허용 코드/독음 10,384쌍과 후보 뜻 레코드 29,497개에 판정을 기록했다. 같은 글자·인쇄된 독음·뜻을 법원/보조 사전 사이에서 대조하고 기존 선택 검수 근거를 재검증했다. 자동 일치 판정과 Codex 개별 판정을 구분한다. 개별 비교 판정은 13건(확인 12/보류 1)이며 실제 사람이 전 항목을 검수했다고 표시하지 않는다. 원문은 변경하지 않고 단일 catalog의 각 뜻 `audit`, 독음별 `review`, 글자별 `review_status`와 `semantic_audit` 집계에 저장했다. 전체에 판정이 있다는 것은 모든 뜻이 확인됐다는 의미가 아니다.

전 허용 독음에 확인한 뜻이 있는 코드 4,132, 일부 독음만 확인한 코드 279, 확인 뜻이 없는 코드 5,084다. 확인 뜻을 가진 글자 합계 4,411, 확인한 코드/독음 4,522쌍·한자/독음/뜻 4,826조합이다. 나머지 허용 코드/독음 5,862쌍은 보류다. 후보 뜻 판정은 source_agreement 4,445/editorial 369/adjudicated 12, 나머지는 사전 표현 차이·단일 근거·영어 글자 범위·독음 표지 없음·허용 독음 아님·전용 문자 등의 사유로 보류했다. 표현 차이를 모두 의미 충돌이나 오류로 단정하지 않는다. 동의어 관계를 확인하지 못한 뜻도 보류에 포함된다.

기존 libhangul IME 키를 뜻의 독음으로 쓰지 않고 원문 끝에 실제 인쇄된 독음을 분리했다. 윤 키 아래의 륜 표기를 윤으로 복사하지 않는다. 공백만 다른 동일 뜻은 참조를 합쳤고 표지 없는 조각도 보류 상태로 보존했다. 坪은 벌판/level ground, 鉉은 솥귀/device for carrying a tripod를 채택하고 원래 법원 뜻은 보류했다. 金의 김=성씨, 昭의 소=밝을 등은 해당 독음의 별도 근거로 판정했다. 堈의 언덕은 질그릇 영문 뜻과 차이를 해소하지 못해 보류했다.

확인한 뜻에 명시적 소재 규칙을 적용해 총 270자(목80/화55/토40/금17/수78)를 연결했다. 吹의 불은 바람을 불다, 腺의 샘은 분비샘으로 설명하고 화/수 소재를 배제했다. 다의어인 불/물/돌/산/샘/쇠/철 등은 영어 문맥 조건도 확인한다. 글자의 부수나 보석·지혜·아름다움 등 추상적 인상으로 임의 오행을 붙이지 않았다. 검수된 뜻과 독음에만 소재를 연결하고 이름 적합성은 미평가로 유지한다.

검색 스키마를 v3으로 갱신하고 기본 독음/뜻/소재 검색은 확인 뜻만 반환하게 했다. 글자·코드 조회는 모든 근거를 보여 주며 보류/부분확인은 review-status 필터로 조회한다. 같은 글자의 다른 뜻/독음과 오행이 섞이지 않도록 같은 의미 레코드에서 조건을 확인한다. 자료 폴더 3파일·전체 변경 21파일 구조를 유지했고 catalog는 5,484,151바이트로 기존 8MB 한도 안이다.
