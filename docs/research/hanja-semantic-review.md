# 한자 뜻과 오행 소재 검수 기록

확인일: 2026-11-04. 자료: [hanja-semantic-review.json](../../data/hanja-semantic-review.json). 검수 방식은 Codex의 출처 대조·프로젝트 편집 판단이며 실제 사람 검수나 전통 작명 판정이 아니다.

2026-11-05 의미 개념 재검토에서 아래 과거 소재 판정 일부가 보류/미분류/재분류됐다. 현재 159개 개념·315개 개별 판정과 소재 318자는 [현재 안내](../../data/hanja/README.md)를 따른다. 아래 344자 표를 현재 오행 승인 목록으로 사용하지 않는다.

현재 전수 판정은 [전체 데이터 안내](../../data/hanja/README.md)를 따른다. 아래 344자 표는 최초 선택 검수의 기준 기록이며 나머지 한자의 현재 상태는 catalog의 항목별 `review`와 뜻별 `audit`에 있다. 坪·鉉 등 후속 판정은 기존 기준 기록을 지우지 않고 개별 비교 근거와 함께 추가했다.

## 범위와 결과

공식 색인 고유 코드 9,495개 가운데 이름 조합 소재와 기존 33자를 중심으로 344자를 선별 검토했다. 모든 한자를 검수했다고 표시하지 않는다. 341자의 선택한 뜻·독음은 출처에 연결했고 그중 239자를 목72/화49/토30/금17/수71로 연결했다. 나머지 102자는 뜻을 확인했지만 오행 미분류, 3자는 뜻 대응 보류다. 8자는 일부 독음만 검수했다. 뜻 확인은 다른 뜻·독음 전체의 검증이나 실제 이름으로 자연스럽다는 판정이 아니다.

전체 9,495코드의 처리 현황은 최초 검증 시 coverage.json에 기록했다. 중복 산출물 정리 후에는 [도구 안내](../../tools/hanja-catalog/README.md)로 필요할 때 재생성한다. 의미 출처 확인341, 의미 보류3, 구조적 보류1259, 아직 의미 미검수7892로 나뉜다. 구조적 보류와 의미 검수 상태를 섞어 모든 나머지를 미분류 검수 완료로 만들지 않는다.

## 적용 기준

- 의미 사실과 오행 연결을 분리한다. 물·나무·불·흙·금속의 구체적 뜻이나 선언한 활동/기구 소재를 프로젝트 규칙으로 연결한다. 부수·획수·독음·색상·덕목에서 오행을 추정하지 않는다.
- 목은 나무·식물·식물 부위/재목/곡물·심는 활동, 화는 불·물리적 빛·햇빛·열·불 밝히는 기구, 토는 흙·땅·산·돌·모래/지형, 금은 금속·선택한 금속 악기/광석/제련한 쇠/칼날, 수는 물·수계·수분·강수/물에서의 활동에 연결한다. 이 규칙은 전통 한자 오행표/자원오행/용신 판정이 아니다.
- 기구는 재료가 명확하지 않으면 보류한다. 거울/팔찌/벼루/피리의 재료를 자동 추정하지 않는다. 금속 악기 연결도 프로젝트가 선택한 소재 해석이며 모든 제작 재료가 같다는 주장이 아니다.
- 다의어는 선택한 뜻에만 적용한다. 金의 금=쇠와 김=성씨, 葉의 엽=잎과 섭의 미확인 뜻을 구분한다. 均/若/昭/炤/芸/葉/金/釗는 미검수 독음을 따로 남겼다.
- 浩의 넓을, 峻의 높을, 錦의 비단, 鈺의 보배, 彬의 문채를 나타내는 빛날, 若의 같을 등에 소재를 억지로 부여하지 않는다. 가을을 금, 하늘을 화로 자동 배속하지도 않는다.
- 潤은 젖을 뜻을 수로, 藍은 식물 쪽 뜻을 목으로 연결했다. 기존 런타임의 윤택함/쪽빛 해석을 덮어쓰지 않았다. 渚는 사주팔자가 아닌 沙洲(모래톱) 뜻을 토의 지형 소재로 선택했다.
- 꽃/무덤/눈물/불/무기 등 다른 뜻이나 선택한 뜻에 주의가 필요한 사례는 `usage_cautions`로 남겼다. 긍정적인 한자쌍/자연스러운 이름이라는 자동 합격 표시는 하지 않는다.

## 출처·원문 문제 처리

법원 허용 독음은 기존 공식 스냅샷으로 확인했다. 기초 뜻은 법원 `in` 필드와 고정 [Unicode 17 Unihan](https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip)의 kDefinition을 대조했다. Unihan은 뜻 맥락의 보조 자료이며 한국 인명용 허용 독음을 대체하지 않는다. Unihan의 중국어/다른 언어 맥락은 한국어 훈과 항상 같지 않다. 각 행에 실제 선택한 뜻의 원출처를 기록했고, 보조 정의의 해시는 대조 근거이지 두 정의가 동의어라는 자동 인증이 아니다. 湳·煐에는 Unihan 17 정의가 없어 법원 뜻만 확인했다.

법원 짧은 훈과 보조 정의에 차이가 있는 菫/蘿/蕊/稷/景/煦/澔/汨/彬 등은 개별 주석을 남겼다. 뜻을 조용히 통합하거나 사전 원문 오류를 고친 것처럼 표시하지 않는다.

법원 자료는 [출처 표시 정책](https://efamily.scourt.go.kr/sm/SmBottomCopyProtecPolic.do)에 따라 [대한민국 법원 전자가족관계등록시스템](https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010)을 명시한다. Unihan 출처·고정 해시와 [Unicode 고지](../../tools/hanja-catalog/LICENSES.md#unicode)를 보존한다. 법원 원문·기존 PDF/초안·기존 33자 분류·앱/DB는 유지했다. 기존 이름 추천 결과는 이번 검수로 바뀌지 않는다.

## 재검증과 남은 작업

`python3 -m scripts.hanja_semantics`는 검수 데이터의 출처 버전, 공식 전체 페이지의 해시/필터/건수, 글자·독음별 선택 훈, Unihan 명시 구절, 미검수 독음, 소재/오행 대응, 보류 항목의 가점 금지, 이름 적합성 미평가 상태를 검증한다. 이 검증기는 편집자가 정한 해석 자체의 언어학적 정답을 증명하지는 않는다. 실행 명령은 [도구 안내](../../tools/hanja-catalog/README.md)를 따른다.

모든 항목의 `recommendation_ready=false`, `catalog_ready=false`를 유지했다. 전체 법적 별표 대응/전용 코드 매핑과 실제 사람의 뜻·이름 자연스러움 검토가 남아 있다. 후속 조합기는 `reviewed_readings`와 `selected_court_gloss` 또는 명시한 Unihan 근거를 함께 사용해야 한다. 같은 글자의 모든 독음/뜻에 소재를 복사하지 않는다. 이번 344자는 검수 범위이며 최종 후보 상한이 아니다.


검증 결과: 새로운 의미 검증 테스트 10개를 포함한 Python 회귀 64개 통과. 실제 공식 캐시/고정 Unihan/검수 파일을 대조한 오프라인 검증과 전체 산출물 해시 확인도 통과했다. 격리된 `scripts/hanja_semantics.py`의 Codex Security 검사 완료, 발견/보류/open question 0건이며 최종 코드가 검사 사본과 같다. 기존 앱·DB·화면을 변경하지 않아 Node/DB/빌드는 반복하지 않았다. 추가 Meta 호출·커밋·PR·배포는 없다.
