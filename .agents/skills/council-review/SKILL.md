# Council 계획 검토

대상 계획과 관련 결정 문서를 확인한 뒤 메인 에이전트가 다음 다섯 관점으로 검토하고 합성한다. 각 관점마다 subagent를 의무적으로 만들지 않는다. 근거 수집·단순 탐색의 위임은 실행 환경에서 허용할 때만 사용하고, 사용자가 독립 병렬 리뷰를 요청한 경우에만 관점별 리뷰를 위임한다. 모든 출력은 한국어로 작성한다.

1. 반대자: 실패를 가정하고 원인, downstream 피해, 가장 위험한 가정을 찾는다.
2. 제1원칙: 실제 문제, 핵심과 부가 범위, 순서, 아직 불필요한 작업을 가른다.
3. 확장자: 놓친 기회, 재사용 가능한 기반, 제품 경쟁 우위를 찾는다.
4. 외부자: 처음 보는 사람이 이해하지 못할 지점, 모순, 빠진 맥락을 찾는다.
5. 실행자: 첫 행동, 장기 리드타임, 불명확한 태스크와 현실적 소요를 검토한다.

그 뒤 합성 검토에서 근거가 있는 발견만 비교하고 중복을 제거한다. 중요한 맹점이나 관점들이 공유하는 미검증 전제가 확인된 경우에만 제시한다. 즉시 반영할 조치와 보류할 제안을 구분하되, 발견이 없으면 없다고 명시한다.

사용자가 요청한 독립 검토를 실행할 수 없을 때만 그 제한을 밝힌다. 발견이 없는 관점의 분량을 억지로 채우지 않는다.
