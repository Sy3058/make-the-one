# 외부 한자 자료 라이선스·출처 고지

자료별 원문 고지와 적용 범위를 한곳에 모았다. 이 문서가 모든 자료나 앱 코드에 하나의 공통 라이선스를 부여하는 것은 아니다.

<a id="court"></a>

## 법원 원문 - 출처 표시

법원 원문 출처는 [대한민국 법원 전자가족관계등록시스템](https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010)이며 [저작권 정책](https://efamily.scourt.go.kr/sm/SmBottomCopyProtecPolic.do)의 출처 표시 조건을 따른다. 제3자 자료·폰트·이미지에 대한 포괄 허가로 확대하지 않는다.
