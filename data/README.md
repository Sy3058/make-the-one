# 데이터 출처와 검증 범위

## 절기 기준값

`kasi-solar-terms.json`은 [KASI 공식 절기 배포](https://astro.kasi.re.kr/kor/almanac/solarTerms/download)의 1980-2039년 1,440개 항목이다. 원본 배포 범위는 1920-2100년이며 2026-09-01 기준 자료다. 원본 SHA-256과 보조 2024 역서 출처를 JSON 메타데이터에 기록했다. 미래 시각에는 지구 자전 예측의 불확실성이 있다.

KASI는 서머타임과 무관하게 고정 UTC+09:00을 사용하고 반올림 시각을 24:00으로 쓸 수 있다. 이를 다음 날 00:00으로 정규화했다. 엔진 시각을 분으로 반올림해 비교하며 1분 초과는 실패한다. 보고서에는 원시 초 오차도 남기고 실제 절기 계산에는 반올림을 적용하지 않는다.

## 이름 자료

2026-11-02 제품 변경으로 재미 이름은 추천·API 응답에서 제외했다. 기존 별명 자료와 DB 행은 보존하지만 일반 이름 최소 72개만 적재 완료조건으로 검사하며, 별명 보유 여부는 추천 성공 조건이 아니다.

`names.json` v3는 한자 이름 82개, 순우리말 이름 2개와 프로젝트가 만든 별명 12개다. 별명은 추천하지 않는다. [대법원 인명용 한자 안내](https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010)와 공식 한자 조회 응답으로 사용 한자 33개의 허용 여부·독음을 확인했다. 글자별 조회 URL·확인일·응답 해시를 보관한다. 기초 뜻은 [Unicode 17 Unihan](https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip) 자료도 대조해 짧은 한국어 풀이로 기록했다.

글자의 기초 뜻은 출처 기반 사실이다. 이름 전체 뜻·모티프·스타일은 프로젝트의 창작적 조합이며 전통 어원이나 사전 등재 이름 뜻으로 설명하지 않는다. 별명은 한자·어원 주장이 없는 별도 창작물이다. Codex의 초기 편집 검토를 거쳤으며 자연스러움 점수는 주관적이다. 실제 사람의 20개 서사 검토와 최종 이름 선호도 확인은 남아 있다.

검증기는 미확인 한자·틀린 독음·미검수 항목·중복 이름·알 수 없는 모티프를 거부한다. 적재기는 기존 동일 ID의 다른 내용을 덮어쓰지 않는다. 기존 v1의 의미·한자·태그 등 내용이 일치할 때만 corpus_version을 v2로 올린다. name_kind·name_feels·word_meaning은 원본 자료에서 관리하고 DB의 검증된 내용이 일치하는 행에만 결합한다.

## 좌표와 생성 자료

`places.json`의 좌표는 도시 대표점이며 정확한 출생 장소 좌표가 아니다. 2026-11-01 GeoNames 한국 덤프와 기존 19개 GeoNames 도시를 대조해 18개를 확인했다. 대전 좌표는 현재 덤프와 불일치해 재확인 대기다. 목포는 기존 UNGEGN 출처의 별도 대표점이다. 이 작업에서 기존 좌표는 변경하지 않았다. GeoNames 자료는 CC BY 4.0이며 [출처·라이선스](https://www.geonames.org/export/)를 따른다.

`data/generated/`는 Git에서 제외한다. 파일 해시·건수·라이브러리 버전·시간 범위·절기 검증 결과를 manifest에 남긴다. 검증된 작은 색인은 2024년 서울·성남·속초·목포만 포함한다. 파일과 적재의 검증 완료는 정책의 `draft` 상태나 출시 승인 조건을 바꾸지 않는다.

## 이름 느낌과 순우리말

`name_feels`는 남성적·여성적·중성적 느낌에 대한 프로젝트 편집 분류이며 통계적 성별 사용량이나 사용 자격을 의미하지 않는다. 중성 후보는 남성적·여성적 선호 양쪽에 포함된다. 자연스러움과 느낌에 대한 사람 검수는 남아 있다.

순우리말 `하늘`과 `이슬`은 [국립국어원 하늘](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=20311), [이슬](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=24868)의 첫 번째 뜻을 확인해 자체 요약했다. word_meaning은 확인된 단어 뜻, meaning_ko는 프로젝트가 쓴 창작 이름 풀이이며 원문 정의·예문을 복제하지 않는다. 한자 없음·독음 검증 해당 없음으로 저장하고 확인된 단어 출처·뜻을 필수 검증한다. 두 음절 정책을 유지한다.

1980-2039년 서울·성남·속초·목포 색인은 원국 263,689개, 발생 1,054,804개, 모티프 근거 9,300,991개로 생성하고 파일 해시 검증 후 PostgreSQL에 원자 적재했다. KASI 기준 1,440개 절입의 가장 가까운 분 대조에서 최대 차이 1분으로 기존 게이트를 통과했다. 전체 20개 도시나 사람 품질 검수의 완료를 의미하지 않는다.

## 오행 소재와 통계 자료

`name-elements.json`은 검증된 기초 뜻에서 프로젝트가 정한 소재 연결표다. 간지의 오행 배속과 이름 글자의 의미 분류를 구분한다. 33개 한자 모두 기존 뜻/출처/응답 해시와 결합하고 그중 7자만 목(英·材·林)·화(景·溫)·수(河·潾)로 연결한다. 나머지 26자는 미분류, 토·금은 근거 후보 부족으로 가점이 없다. 하늘은 미분류, 이슬은 확인된 단어 뜻을 수에 연결한다. 분류 자체는 공식 법원 한자 속성이나 용신 판정이 아니다.

`name-statistics/`의 2025년 전국·남녀 TOP20 40개 행은 법원 출처를 명시한 네임픽 표(자료 확인일 2026-10-11)에서 수집하고 포근이름의 2025년 표와 이름/순위/건수를 대조했다. 사용자 승인에 따라 외부 집계를 활용했으며 법원 원본 직접 조회는 실패 상태다. 별도 추출물은 설명 문구를 복제하지 않은 집계 사실이며 원문 HTML이 아니다. 자료 URL·원출처 URL·확인일·수집일·기간·지역·성별·상위 범위와 추출물 SHA-256을 보존한다. 추출물 해시 일치와 행 내용 일치는 검증하지만 upstream의 정확성을 새로 증명하지 않는다. 원문에 없는 이름의 빈도/순위를 추정하지 않는다.

아린·아윤·시아·윤서·채아·도아·유하·수호·은호·윤우 10개는 그 통계에서 확인한 한글 이름에 기존 검증 글자를 조합했다. statistics_ref는 집계의 한글 이름에만 연결하며 실제 신고 한자·의미·오행·이름 느낌을 통계로부터 추론하지 않는다. 조합·태그·느낌·자연스러움은 프로젝트 편집 판단이다. 기존 86개 항목과 33자 기초 사실은 유지하고 corpus_version만 v3로 변경했다.

통계 준비 도구는 원문 해시/범위/순위/건수/중복/추가 개인 필드를 검증하고 draft만 내보낸다. raw 해시만으로 숫자 대조를 대신할 수 없으며 자동 추천 승격은 없다. 새 이름을 올리기 전에 출처 대조·한자 독음/허용·단어/글자 뜻·편집 태그·소재 검수를 수행한다. v1/v2 적재 내용이 현재 원본과 같을 때만 v3로 올리며 값이 다르면 트랜잭션 전체를 거부한다.
