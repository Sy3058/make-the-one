# 인명용 한자 데이터

파일 크기에 맞춘 분할을 없애고 용도별로 세 파일만 유지한다.

| 파일 | 역할 |
| --- | --- |
| `catalog.json` | 9,495코드의 문자·허용 독음·중복 제거한 뜻 후보·검수/미해결 상태와 검색 색인 |
| `sources.json` | 모든 원문·요청 조건·시각·라이선스 메타데이터·원본 해시를 보존하는 근거 묶음 |
| `README.md` | 사용법과 데이터 범위 |

최초 344자 선택 검수, 출처 개별 판정 13건, 의미 개념 159개와 뜻·독음별 개별 판정 315건은 상위 [hanja-semantic-review.json](../hanja-semantic-review.json)에 유지한다. 현재 전체 검수 결과는 catalog v4의 `source_audit`(근거 대조)와 `concept_audit`(의미 해소)와 각 항목·뜻의 판정에 있다. 모든 추천 준비 플래그는 false이며 이름 생성기·앱·DB에는 아직 연결하지 않았다.

## 검색

Python 표준 라이브러리만 사용한다. 검색은 `catalog.json`만 읽고 원문은 열지 않는다.

```bash
python3 -B scripts/hanja_inventory.py --character 金
python3 -B scripts/hanja_inventory.py --reading 윤 --meaning 물 --limit 10
python3 -B scripts/hanja_inventory.py --reading 윤 --element water
python3 -B scripts/hanja_inventory.py --review-status held
python3 -B scripts/hanja_inventory.py --review-status partial
python3 -B scripts/hanja_inventory.py --concept plant.flower.violet
python3 -B scripts/hanja_inventory.py --semantic-status held
python3 -B scripts/hanja_inventory.py --character 菫 --meaning 오랑캐꽃
```

한 프로세스에서 `Catalog()`를 한 번 만들어 재사용하면 이후 검색에는 파일 읽기가 없다. 글자·독음·의미 개념·의미 판정 상태·오행 소재·미해결 사유는 직접 색인으로 찾는다. 뜻은 작은 단어 색인의 부분 문자열을 찾고 코드 집합을 교차한 뒤 후보의 같은 뜻/독음인지 확인한다. `물`은 `맑은물`도 찾고 영어 대소문자를 구분하지 않는다. 여러 키워드는 같은 뜻에서 모두 일치해야 한다. 필터는 최대 160자, 뜻 키워드는 8개, 반환 개수는 1-100개다.

뜻이 여러 개인 한자를 여러 파일에 복사하지 않는다. 각 글자는 법원 코드 키로 한 번 저장하며 같은 뜻·독음은 출처 참조 `refs`를 합친다. 영어 뜻은 `reading=null`인 글자 단위 참고 자료다. 독음과 뜻을 함께 검색하면 그 독음에 연결된 뜻만 반환한다. `matched_readings`는 검색 조건에 실제 연결된 허용 독음이다.

법원 주 풀이, 법원 일반 사전, libhangul 순의 출처 우선순위에 전수 검수 결과를 적용한다. 출처 대조 또는 별도의 의미 개념 판정을 통과한 뜻만 기본 독음/뜻 검색에 반환한다. 오행 검색은 승인된 개념의 구체 소재 규칙이 있는 뜻만 반환한다. 추가·상충 뜻은 원문과 함께 보존한다. 글자/코드만 조회하면 보류 뜻도 볼 수 있다. `--review-status`는 글자별 source_checked/partial/held 상태를 고르며, held 조회에서는 보류 근거도 검색할 수 있다. 김=쇠는 보류하고 김=성씨만 확인된 뜻으로 반환한다.

오행 색인은 현재 318자다(목91/화52/토52/금18/수105). 한 글자가 뜻별로 다른 소재를 가질 수 있으므로 오행별 집계 합과 고유 글자 수는 일반적으로 다를 수 있다. 이번 결과의 합은 318자와 같다. 소재는 같은 글자의 다른 뜻·독음으로 옮기지 않는다. 부수·색상·추상적 인상에서 오행을 추정하지 않으며 전통 작명 오행/용신 판정이 아니다.

## 의미 개념과 소재 판정

`한자 + 허용 독음 + 선택 뜻 → 의미 개념 → 구체 소재 → 프로젝트 오행` 순서로 처리한다. `concepts`의 정의·동의 표현·소재 규칙은 한 벌만 저장하고 각 뜻은 개념 ID를 참조한다. 원문 일치만으로 의미 해소나 오행을 승인하지 않는다.

| 뜻별 semantic_status | 조합 수 | 판정 |
| --- | ---: | --- |
| reviewed | 296 | Codex가 출처를 개별 대조해 개념을 정함 |
| rule_resolved | 204 | 법원과 보조 사전의 같은 허용 독음에서 통제된 동의 표현이 같은 개념에 대응 |
| held | 19 | 개별 대조했지만 의미 차이가 해소되지 않음 |
| unresolved | 28,978 | 승인된 개념 없음. 글자 단위 영어·비허용 독음·전용 코드도 포함 |

분모는 9,495자나 독음 쌍이 아니라 중복을 합친 후보 뜻 레코드 29,497개다. 의미가 확정된 500개 조합에도 오행 미분류가 있다. 뜻의 출처 대조 결과 `audit`와 의미 판정 `semantic_status`는 독립적이다. 예를 들어 사전 표현은 달라도 승인된 동의어는 의미를 해소할 수 있고, 원문 표기가 같아도 다의어는 미해소로 남는다.

기존 오행 연결 270자의 296개 뜻·독음 조합을 빠짐없이 개별 재검토했다. 282개는 개념 확정(그중 지경·칼날 2개는 재료 미확정), 14개는 보류다. 각 판정의 원문 구절·독음·사전 행·이유·이전 소재를 `concept_audit.reviews`에서 역추적할 수 있다. 외부 추가 사실은 URL·확인일·짧은 자체 요약으로 기록한다. 기존 344자 편집 입력은 과거 기준 기록으로 유지하며 현재 오행 승인에 그대로 복사하지 않는다.

- 제비꽃/오랑캐꽃은 같은 개념, 제비꽃/국화는 다른 개념이다. 같은 목 소재라고 동의어로 묶지 않는다. 승인된 개념의 동의 표현은 뜻 검색에도 적용한다.
- 불꽃/바람을 불다, 물샘/분비샘, 납 금속/밀랍, 주석 금속/풀이, 평지 땅/식물 등은 분리한다. 다의 표현은 후보 개념만 남기며 두 자료가 같은 단어를 써도 자동 승인하지 않는다.
- 鍾의 쇠북, 蘿의 미나리 등은 출처 차이를 해소하지 못해 보류한다. 蕓의 평지, 磺의 쇠돌/쇳돌, 檍의 참죽나무도 추가 보류했다. 芷의 어수리와 棠의 팥배나무도 보조 자료의 식물 정체와 대응을 확정하지 못해 보류했다.
- 域의 지경·鋒의 칼날·鉉의 솥귀·玉의 옥은 의미와 재료를 구분한다. 汀·沚·濱의 물가 지형은 물 자체가 아닌 땅의 가장자리로 선택했다.

`--semantic-status`는 뜻별 reviewed/rule_resolved/held/unresolved를 고른다. `--review-status`는 기존 **출처 대조의 글자별** 상태다. 보류/미해소 뜻을 명시적으로 검색하면 참고 근거도 조회한다. 두 필터가 같은 의미는 아니다.

## 검증과 갱신

```bash
python3 -B scripts/hanja_inventory.py --check
python3 -B scripts/hanja_inventory.py --build
python3 -B -m unittest discover -s tests -p 'test_hanja_*.py' -v
```

`--check`는 원문 파일별 기존 바이트 수·SHA-256·공식 전체 페이지를 재검증하고 검색 데이터와 모든 색인을 다시 계산해 비교한다. `--build`는 원문과 편집 자료에서 검색 파일 하나만 다시 만든다. 건수·원문/편집 해시·정책은 catalog 안에 있으므로 별도 manifest·누락 파일·생성 Markdown 표는 두지 않는다. 미해결 목록은 `--issue`로 검색한다. `refs`는 법원 전체 행 인덱스와 풀이 인덱스, 사전 원본 행 번호, Wiktionary 개정 번호와 원문 행을 가리킨다.

`sources.json`은 원문을 중복 없이 한 번씩 보존한다. 내부 문서 ID는 기존 해시 근거를 잇기 위한 키이며 실제 분할 파일이 아니다. 원본 JSON 바이트는 구조에서 재현하고, 비표준 형식 응답 5개는 원문 문자열을 그대로 보존해 기존 해시가 유지된다. 수집/과거 검수의 재현은 [도구 안내](../../tools/hanja-catalog/README.md)를 따른다.

## 출처와 남은 범위

출처 메타데이터는 `sources.json`의 `manifest.sources`에 있다. [법원 조회](https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010)와 [저작권 정책](https://efamily.scourt.go.kr/sm/SmBottomCopyProtecPolic.do), [libhangul BSD 고지](../../tools/hanja-catalog/LICENSES.md#libhangul), [Unicode License v3](../../tools/hanja-catalog/LICENSES.md#unicode), [Wiktionary CC BY-SA 고지](../../tools/hanja-catalog/LICENSES.md#wiktionary)를 유지한다. 영어 뜻·이체자 관계로 한국어 허용 독음이나 뜻을 상속하지 않는다.

표준 문자 9,090자 중 9,015자는 한국어/영어 뜻 근거가 있고 75자는 미해결이다. 전용 코드 405개, 한국어 뜻 연결이 없는 허용 코드/독음 1,109쌍, 허용 독음 원문 누락 1코드 등의 상태를 보존한다. 9,495는 기술 코드 수이며 법원의 2024년 발표 9,389자와 단위가 다르다. 전체 법적 별표 대응·뜻/독음·자연스러움 검수는 미완료다.

## 전수 뜻·독음 검수 결과

2026-11-05, 9,495코드·허용 코드/독음 10,384쌍·후보 뜻 레코드 29,497개를 모두 판정했다. 자동 사전 대조, 기존 Codex 선택 검수와 개별 판정을 구분하며 사람 검수로 표시하지 않는다.

| 글자별 상태 | 코드 수 | 의미 |
| --- | ---: | --- |
| source_checked | 4,132 | 모든 허용 독음에 하나 이상 근거 확인한 뜻이 있음 |
| partial | 279 | 일부 허용 독음에만 확인한 뜻이 있음 |
| held | 5,084 | 확인한 독음별 뜻이 없거나 문자/독음 문제가 남음 |

총 4,411자에 확인한 뜻·독음 조합이 있고, 코드/독음 4,522쌍·한자/독음/뜻 4,826조합이 근거 확인 상태다. 나머지 허용 코드/독음 5,862쌍은 보류다. source_checked 글자에도 다른 뜻이 보류일 수 있다. 후속 조합기는 각 뜻의 근거와 별도 `semantic_status`·`concept`·소재 규칙을 함께 확인해야 한다. 글자별 상태만으로 모든 뜻을 승인하지 않는다.

판정 기준:

- 법원과 보조 사전의 같은 글자·명시적 독음·공백 제외 같은 뜻이 일치하면 source_agreement. 자동 근거 대조 결과이며 개별 Codex 판정과 구분한다.
- libhangul의 입력 키를 독음으로 간주하지 않고 뜻 뒤에 실제 인쇄된 독음 표지를 확인한다. 단독 `쇠` 같은 표지 없는 조각은 dictionary_marker로 보류한다.
- 기존 344자 선택 검수의 원문·뜻·독음·정의 해시를 다시 검증했다. 선택한 17/18 버전 정의는 모두 동일하다. 확인한 선택 뜻만 editorial 판정을 받는다.
- 개별 판정 13건 중 12건은 source_checked, 1건은 held다. 坪의 벌판·鉉의 솥귀를 채택하고 기존 돌·활시위 등의 뜻은 보류했다. 吹의 불은 바람을 불다, 腺의 샘은 분비샘으로 설명하고 화/수 소재를 배제했다. 堈의 언덕은 영문 질그릇 뜻과 차이가 해소되지 않아 보류했다.
- 표현이 다르다는 이유만으로 틀렸다고 판정하지 않는다. 동의어·출처 차이를 확정하지 못한 뜻은 source_difference, 근거가 하나뿐이면 single_source로 보류한다. 영어 글자 뜻은 한국어 독음에 자동 연결하지 않는다.

각 뜻의 `audit`는 catalog의 `source_audit.sense_rules`에 있는 상태·사유를 가리킨다. `adjudication`은 같은 파일의 개별 판정 번호이고, 모든 판정의 비교 구절·출처·이유는 원본 편집 JSON에도 있다. `editorial` 필드는 최초 344자 선택 검수의 기준 기록이며 현재 전수 상태인 `review`/`review_status`와 구분한다. 현재 오행 연결은 위 의미 개념 판정을 별도로 통과한 뜻에만 부여한다.

전체 의미가 맞다고 확정하거나 모든 한자를 이름 후보로 승격하지 않았다. 단일 출처·표현 차이·전용 코드·누락의 추가 해소와 완성된 이름의 자연스러움 평가는 남아 있다. 전수 대조 완료와 전체 뜻 승인·실제 사람 검수·이름 적합성 완료는 구분한다.
